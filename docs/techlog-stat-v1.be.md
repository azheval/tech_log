# techlog-stat v1

## CLI-Кантракт

```text
techlog-stat <report> --input <dir> --glob <pattern> --output <dir> [--top N] [--format list] [--workers N] [--filter key=value] [--duration value]
```

## Сцягі

- `--input`
  Каранёвы каталог для пошуку логаў.
- `--glob`
  Маска файлаў адносна `--input`, напрыклад `*/*.log` або `rphost_*/*.*`.
  Падтрымліваюцца wildcard-сімвалы `*` і `?`.
  Раздзяляльнік шляху ўнутры шаблону павінен быць `/`.
  Рэкурсіўны `**` не падтрымліваецца.
- `--output`
  Каталог выніку аднаго запуску.
- `--top`
  Максімальная колькасць радкоў у ранжыраваным вывадзе, па змаўчанні `100`.
- `--format`
  Фарматы праз коску: `text`, `csv`, `json`.
- `--workers`
  Паралелізм на ўзроўні файлаў, па змаўчанні `1`.
- `--filter`
  Фільтр па сырым падзеі ў форме `key=value`.
  Сцяг можна паўтараць.
  Усе фільтры аб'ядноўваюцца праз `AND`.
  Адсутнае поле не выклікае памылку, але падзея не супадае.
- `--duration`
  Мінімальны парог працягласці зыходнай падзеі.
  Фільтр прымяняецца да агрэгацыі.
  1С захоўвае працягласць у мікрасекундах, але CLI прымае зручны парог.
  Голы лік трактуецца як секунды: `--duration 5` эквівалентна `5s`.
  Падтрымліваюцца суфіксы `us`, `ms`, `s`, `m`.

## Кантракт Выхадных Файлаў

Кожны запуск стварае асобны каталог выніку:

```text
<output>/
  summary.txt
  contexts.csv або errors.csv
  run.json
  errors.log
```

## summary.txt

Чалавекачытальная справаздача ўключае:

- назву справаздачы
- час генерацыі
- уваходныя параметры
- лічыльнікі файлаў
- агульную колькасць падзей
- агульную працягласць
- сярэднюю працягласць
- ранжыраваныя радкі

## CSV-Вывад

Кантэкстныя справаздачы запісваюць `contexts.csv`:

```text
rank,context,short_context,total_duration_ms,time_pct,count,count_pct,avg_duration_ms
```

Справаздачы па памылках запісваюць `errors.csv`:

```text
rank,event,description,short_description,total_duration_ms,time_pct,count,count_pct,avg_duration_ms
```

## run.json

Метададзеныя выканання ўключаюць:

- версію ўтыліты
- тып справаздачы
- часавыя меткі
- працягласць запуску
- уваходныя і выхадныя шляхі
- лічыльнікі файлаў
- аб'ём прачытаных дадзеных
- выбраныя параметры

## errors.log

Памылкі асобных файлаў і анамаліі парсінгу, якія не спыняюць увесь запуск.
